## 2. 核心技术难点分析

### 2.1 微服务拆分与服务间通信

#### 2.1.1 难点描述

微服务拆分是整个架构设计的基石。拆分不当会导致：
- **服务边界模糊**：频繁的跨服务调用，增加网络开销
- **数据耦合**：服务间共享数据库，破坏独立性
- **循环依赖**：服务A调用B，B又调用A，形成死锁风险
- **分布式事务复杂化**：跨服务的数据一致性难以保证

#### 2.1.2 困难原因

1. **业务边界识别**：短视频平台业务交叉复杂，视频与用户、互动、社交紧密关联
2. **数据归属权**：点赞数应该属于Video服务还是Interaction服务？
3. **通信效率**：RPC调用引入网络延迟，批量操作需要聚合查询
4. **服务粒度**：过细导致调用链过长，过粗失去微服务优势

#### 2.1.3 技术方案

**服务拆分原则**：
```
采用 DDD (领域驱动设计) 方法论：
1. 识别限界上下文 (Bounded Context)
2. 每个服务拥有独立数据库 (Database per Service)
3. 通过领域事件实现服务解耦
```

**RPC框架选型 - Kitex**：
```go
// 选择字节跳动开源的Kitex框架
// 优势：
// 1. 高性能：基于Netpoll网络库，性能优于gRPC
// 2. 代码生成：Thrift IDL自动生成服务端/客户端代码
// 3. 服务治理：内置熔断、限流、超时控制
// 4. 扩展性：支持中间件链式调用

// IDL定义示例 (idl/video.thrift)
service VideoService {
    PublishResponse Publish(1: PublishRequest req)
    VideoListResponse List(1: VideoListRequest req)
    DetailResponse Detail(1: DetailRequest req)
}
```

**服务间通信模式**：
```go
// 同步调用 - Kitex RPC
func (h *Handler) GetVideoWithAuthor(ctx context.Context, videoID int64) (*VideoDetail, error) {
    // 1. 获取视频信息 (本地服务)
    video, err := h.videoUC.GetVideo(ctx, videoID)

    // 2. 调用User服务获取作者信息 (RPC调用)
    author, err := rpc.GetUserInfo(ctx, video.UserID)

    // 3. 聚合返回
    return &VideoDetail{Video: video, Author: author}, nil
}

// 异步通信 - Kafka消息队列
func (s *Service) PublishVideo(ctx context.Context, video *model.Video) error {
    // 1. 保存视频元数据
    if err := s.db.CreateVideo(ctx, video); err != nil {
        return err
    }

    // 2. 发送异步消息，后续处理（索引、推荐、封面生成）
    s.mq.SendMessage(ctx, &VideoCreatedEvent{VideoID: video.ID})
    return nil
}
```

**解决循环依赖**：
```
                    ┌─────────────┐
                    │   Gateway   │
                    └──────┬──────┘
                           │
           ┌───────────────┼───────────────┐
           ▼               ▼               ▼
    ┌──────────┐    ┌──────────┐    ┌──────────┐
    │   User   │    │  Video   │    │  Social  │
    └──────────┘    └──────────┘    └──────────┘
           ▲               │
           │               │ 异步事件
           └───────────────┘

    规则：下层服务不能调用上层服务
    视频服务需要用户信息时，通过Gateway聚合
    或通过事件总线异步获取
```

### 2.2 分布式数据一致性

#### 2.2.1 难点描述

微服务架构下，数据分散在多个服务的独立数据库中。当一个业务操作涉及多个服务时，如何保证数据一致性成为核心挑战。

**典型场景**：
- 用户点赞视频：需要更新Interaction服务的点赞记录 + Video服务的点赞计数
- 视频删除：需要删除Video记录 + 删除所有相关评论 + 删除点赞记录 + 清除ES索引

#### 2.2.2 困难原因

1. **CAP定理约束**：分布式系统无法同时满足一致性、可用性、分区容错性
2. **网络不可靠**：RPC调用可能超时、失败、重复
3. **回滚复杂**：跨服务事务无法使用数据库原生回滚
4. **数据冲突**：并发操作可能导致计数器不一致

#### 2.2.3 技术方案

**最终一致性 + 事件驱动**：
```go
// 采用 SAGA 模式处理分布式事务
// 以点赞为例：

// 1. Interaction服务 - 创建点赞记录
func (s *Service) LikeVideo(ctx context.Context, userID, videoID int64) error {
    // 本地事务
    tx := s.db.Begin()
    defer tx.Rollback()

    // 创建点赞记录（幂等操作）
    if err := s.db.CreateLike(ctx, userID, videoID); err != nil {
        return err  // 已点赞则返回
    }

    // 发送领域事件
    event := &VideoLikedEvent{
        UserID:    userID,
        VideoID:   videoID,
        Timestamp: time.Now(),
    }
    if err := s.mq.Publish(ctx, "video.liked", event); err != nil {
        return err
    }

    tx.Commit()
    return nil
}

// 2. Video服务 - 消费事件更新计数
func (c *Consumer) HandleVideoLiked(ctx context.Context, event *VideoLikedEvent) error {
    // 使用Redis原子操作增加计数
    return c.cache.IncrementLikeCount(ctx, event.VideoID)
}
```

**幂等性设计**：
```go
// 所有写操作必须支持幂等，防止重复执行

// 点赞操作幂等实现
func (db *LikeDB) CreateLike(ctx context.Context, userID, videoID int64) error {
    like := &model.Like{
        UserID:  userID,
        VideoID: videoID,
    }
    // 使用 UNIQUE KEY (user_id, video_id) 保证幂等
    // INSERT IGNORE 或 ON DUPLICATE KEY UPDATE
    result := db.gorm.Clauses(clause.OnConflict{DoNothing: true}).Create(like)
    if result.RowsAffected == 0 {
        return ErrAlreadyLiked
    }
    return result.Error
}
```

**计数器一致性 - Redis + 定时同步**：
```go
// 热点数据使用Redis缓存，定期同步到MySQL

// 实时更新Redis
func (c *VideoCache) IncrementLikeCount(ctx context.Context, videoID int64) error {

// 定时任务同步到MySQL（每5分钟）
func (s *SyncService) SyncLikeCounts(ctx context.Context) error {
    keys, _ := s.redis.Keys(ctx, "video:like_count:*").Result()
    for _, key := range keys {
        videoID := extractVideoID(key)
        count, _ := s.redis.Get(ctx, key).Int64()
        s.db.UpdateLikeCount(ctx, videoID, count)
    }
    return nil

```

**补偿机制**：
```go
// 事务失败时的补偿处理

type SagaOrchestrator struct {
    steps []SagaStep
}

type SagaStep struct {
    Execute    func(ctx context.Context) error
    Compensate func(ctx context.Context) error
}

func (s *SagaOrchestrator) Run(ctx context.Context) error {
    var executedSteps []SagaStep

    for _, step := range s.steps {
        if err := step.Execute(ctx); err != nil {
            // 执行补偿
            for i := len(executedSteps) - 1; i >= 0; i-- {
                executedSteps[i].Compensate(ctx)
            }
            return err
        }
        executedSteps = append(executedSteps, step)
    }
    return nil
}
```

### 2.3 AI语义搜索系统

#### 2.3.1 难点描述

传统的关键词搜索无法理解用户意图。用户搜索"学习编程的视频"，可能匹配不到标题为"Python入门教程"的视频。AI语义搜索需要：
- 理解用户查询的语义意图
- 将文本转换为向量表示
- 在高维向量空间中进行相似性搜索
- 结合全文搜索提供混合检索

#### 2.3.2 困难原因

1. **向量生成延迟**：调用OpenAI API生成embedding需要网络请求
2. **向量存储选型**：专业向量数据库vs内存向量库vs ES向量搜索
3. **相似度算法**：余弦相似度vs欧氏距离vs点积
4. **结果融合**：如何合并全文搜索和语义搜索的结果
5. **成本控制**：OpenAI API按token计费

#### 2.3.3 技术方案

**向量生成 - OpenAI Embedding**：
```go
// app/video/infrastructure/embedding/openai.go

type OpenAIEmbedding struct {
    client  *openai.Client
    model   string  // text-embedding-3-small
}

func (e *OpenAIEmbedding) GenerateEmbedding(ctx context.Context, text string) ([]float32, error) {
    resp, err := e.client.CreateEmbeddings(ctx, openai.EmbeddingRequest{
        Model: e.model,
        Input: []string{text},
    })
    if err != nil {
        return nil, err
    }

    // 转换为float32切片
    embedding := make([]float32, len(resp.Data[0].Embedding))
    for i, v := range resp.Data[0].Embedding {
        embedding[i] = float32(v)
    }
    return embedding, nil
}

// 视频入库时生成embedding
func (s *Service) IndexVideo(ctx context.Context, video *model.Video) error {
    // 组合标题+描述+标签生成embedding

    embedding, err := s.embedding.GenerateEmbedding(ctx, text)
    if err != nil {
        return err

    // 存储到向量数据库
    return s.vectorDB.StoreVector(ctx, video.ID, embedding, &model.VideoMetadata{
        Title:    video.Title,
        Category: video.Category,
```

```go
// 1. 纯Go实现，无外部依赖
// 2. 嵌入式运行，部署简单

func NewChromemDB(collectionName string) (*ChromemDB, error) {
    db := chromem.NewDB()

    // 创建集合，指定维度和距离函数
    collection, err := db.CreateCollection(collectionName, map[string]string{},

func (c *ChromemDB) StoreVector(ctx context.Context, id int64, vector []float32, metadata *model.VideoMetadata) error {
    doc := chromem.Document{
        ID:        strconv.FormatInt(id, 10),
        Embedding: vector,
        Metadata: map[string]string{
            "title":    metadata.Title,
            "category": metadata.Category,
        },
    }
    return c.collection.AddDocument(ctx, doc)
}

func (c *ChromemDB) SearchSimilar(ctx context.Context, queryVector []float32, limit int32) ([]int64, []float32, error) {
    results, err := c.collection.Query(ctx, queryVector, int(limit), nil, nil)
    if err != nil {
        return nil, nil, err
    }

    ids := make([]int64, len(results))
    scores := make([]float32, len(results))
    for i, r := range results {
        ids[i], _ = strconv.ParseInt(r.ID, 10, 64)
        scores[i] = r.Similarity
    }
    return ids, scores, nil
}
```

**混合搜索策略**：
```go
// app/video/domain/service/hybrid_search.go

type HybridSearchService struct {
    es        repository.VideoElastic      // Elasticsearch全文搜索
    vector    repository.VectorDB          // ChromemDB向量搜索
    embedding repository.EmbeddingService  // OpenAI Embedding
    llm       repository.LLMService        // OpenAI LLM
}

func (s *HybridSearchService) Search(ctx context.Context, query string, limit int32) (*SearchResult, error) {
    // 并行执行三种搜索
    var wg sync.WaitGroup
    var esResults, semanticResults []int64
    var relatedQueries []string

    // 1. Elasticsearch全文搜索
    wg.Add(1)
    go func() {
        defer wg.Done()
        esResults, _, _ = s.es.SearchItems(ctx, "videos", &model.VideoES{
            Title:       query,
            Description: query,
        })
    }()

    // 2. 语义向量搜索
    wg.Add(1)
    go func() {
        defer wg.Done()
        queryVector, _ := s.embedding.GenerateEmbedding(ctx, query)
        semanticResults, _, _ = s.vector.SearchSimilar(ctx, queryVector, limit)
    }()

    // 3. LLM生成相关查询建议
    wg.Add(1)
    go func() {
        defer wg.Done()
        relatedQueries, _ = s.llm.GenerateRelatedQueries(ctx, query)
    }()

    wg.Wait()

    // 结果融合 (RRF - Reciprocal Rank Fusion)
    mergedResults := s.reciprocalRankFusion(esResults, semanticResults)

    return &SearchResult{
        VideoIDs:       mergedResults[:limit],
        RelatedQueries: relatedQueries,
    }, nil
}

// RRF融合算法
func (s *HybridSearchService) reciprocalRankFusion(lists ...[]int64) []int64 {
    const k = 60  // RRF常数
    scores := make(map[int64]float64)

    for _, list := range lists {
        for rank, id := range list {
            scores[id] += 1.0 / float64(k+rank+1)
        }
    }

    // 按分数排序
    type idScore struct {
        id    int64
        score float64
    }
    var sorted []idScore
    for id, score := range scores {
        sorted = append(sorted, idScore{id, score})
    }
    sort.Slice(sorted, func(i, j int) bool {
        return sorted[i].score > sorted[j].score
    })

    result := make([]int64, len(sorted))
    for i, is := range sorted {
        result[i] = is.id
    }
    return result
}
```

### 2.4 实时通信系统

#### 2.4.1 难点描述

社交功能要求支持：
- **私信**：一对一实时聊天
- **群聊**：多人聊天室
- **在线状态**：用户在线/离线状态同步
- **消息送达**：离线消息存储与推送

#### 2.4.2 困难原因

1. **连接管理**：维护大量长连接的内存开销
2. **消息路由**：快速找到目标用户的连接
3. **消息顺序**：保证消息按发送顺序到达
4. **断线重连**：连接断开后的消息补发
5. **横向扩展**：多个Gateway实例间的消息广播

#### 2.4.3 技术方案

**WebSocket连接管理**：
```go
// app/gateway/service/ws/manager.go

type Manager struct {
    clients    sync.Map  // map[userID]*Client
    rooms      sync.Map  // map[roomID]map[userID]*Client
    register   chan *Client
    unregister chan *Client
    broadcast  chan *Message
}

type Client struct {
    id       int64
    conn     *websocket.Conn
    send     chan []byte
    manager  *Manager
    rooms    []int64  // 加入的聊天室
}

func NewManager() *Manager {
    m := &Manager{
        register:   make(chan *Client),
        unregister: make(chan *Client),
        broadcast:  make(chan *Message, 256),
    }
    go m.run()
    return m
}

func (m *Manager) run() {
    for {
        select {
        case client := <-m.register:
            m.clients.Store(client.id, client)
            log.Printf("Client %d connected", client.id)

        case client := <-m.unregister:
            if _, ok := m.clients.Load(client.id); ok {
                m.clients.Delete(client.id)
                close(client.send)
                // 从所有聊天室移除
                for _, roomID := range client.rooms {
                    m.removeFromRoom(roomID, client.id)
                }
            }

        case message := <-m.broadcast:
            m.routeMessage(message)
        }
    }
}
```

**消息路由策略**：

```go
// app/gateway/service/ws/router.go

type Message struct {
    Type      string `json:"type"`      // private, group, broadcast
    From      int64  `json:"from"`
    To        int64  `json:"to"`        // userID或roomID
    Content   string `json:"content"`
    Timestamp int64  `json:"timestamp"`
}

func (m *Manager) routeMessage(msg *Message) {
    switch msg.Type {
    case "private":
        // 私信：发送给特定用户
        if client, ok := m.clients.Load(msg.To); ok {
            client.(*Client).send <- msg.Encode()
        } else {
            // 用户离线，存储到数据库
            m.storeOfflineMessage(msg)
        }

    case "group":
        // 群聊：发送给聊天室所有成员
        if room, ok := m.rooms.Load(msg.To); ok {
            roomClients := room.(map[int64]*Client)
            for userID, client := range roomClients {
                if userID != msg.From {  // 不发给自己
                    client.send <- msg.Encode()
                }
            }
        }

    case "broadcast":
        // 全局广播
        m.clients.Range(func(key, value interface{}) bool {
            client := value.(*Client)
            select {
            case client.send <- msg.Encode():
            default:
                // 发送缓冲区满，断开连接
                m.unregister <- client
            }
            return true
        })
    }
}
```

```go
// app/gateway/service/ws/client.go

const (
    writeWait      = 10 * time.Second
    pongWait       = 60 * time.Second
    pingPeriod     = (pongWait * 9) / 10
    maxMessageSize = 512 * 1024
)

func (c *Client) readPump() {
    defer func() {
        c.manager.unregister <- c
        c.conn.Close()
    }()

    c.conn.SetReadLimit(maxMessageSize)
    c.conn.SetReadDeadline(time.Now().Add(pongWait))
    c.conn.SetPongHandler(func(string) error {
        c.conn.SetReadDeadline(time.Now().Add(pongWait))
        return nil
    })

    for {
        _, message, err := c.conn.ReadMessage()
        if err != nil {
            if websocket.IsUnexpectedCloseError(err, websocket.CloseGoingAway) {
                log.Printf("error: %v", err)
            }
            break
        }

        var msg Message
        json.Unmarshal(message, &msg)
        msg.From = c.id
        msg.Timestamp = time.Now().UnixMilli()

        c.manager.broadcast <- &msg
    }
}

func (c *Client) writePump() {
    ticker := time.NewTicker(pingPeriod)
    defer func() {
        ticker.Stop()
        c.conn.Close()
    }()

    for {
        select {
        case message, ok := <-c.send:
            c.conn.SetWriteDeadline(time.Now().Add(writeWait))
            if !ok {
                c.conn.WriteMessage(websocket.CloseMessage, []byte{})
                return
            }

            w, err := c.conn.NextWriter(websocket.TextMessage)
            if err != nil {
                return
            }
            w.Write(message)
            w.Close()

        case <-ticker.C:
            c.conn.SetWriteDeadline(time.Now().Add(writeWait))
            if err := c.conn.WriteMessage(websocket.PingMessage, nil); err != nil {
                return
            }
        }
    }
}
```

```go
// 避免每次访问都写数据库

type CounterBuffer struct {
    mu       sync.Mutex
    counters map[int64]int64  // videoID -> incrementCount
    ticker   *time.Ticker
    db       repository.VideoDB
}

func NewCounterBuffer(db repository.VideoDB) *CounterBuffer {
    cb := &CounterBuffer{
        counters: make(map[int64]int64),
        ticker:   time.NewTicker(5 * time.Second),
        db:       db,
    }
    go cb.flush()
    return cb
}

func (cb *CounterBuffer) Increment(videoID int64) {
    cb.mu.Lock()
    cb.counters[videoID]++
    cb.mu.Unlock()
}

func (cb *CounterBuffer) flush() {
    for range cb.ticker.C {
        cb.mu.Lock()
        if len(cb.counters) == 0 {
            cb.mu.Unlock()
            continue
        }

        // 批量更新数据库
        counters := cb.counters
        cb.counters = make(map[int64]int64)
        cb.mu.Unlock()

        for videoID, delta := range counters {
            cb.db.IncrementVisitCount(context.Background(), videoID, delta)
        }
    }
}
```

```go
func (e *VideoElastic) SearchItems(ctx context.Context, query *model.VideoES) ([]int64, int64, error) {
    // 构建复合查询
    boolQuery := elastic.NewBoolQuery()

    // Must条件：关键词搜索
    if query.Title != "" {
        multiMatch := elastic.NewMultiMatchQuery(query.Title,
            "title^3",       // 标题权重3倍
            "description",
            "tags^2",        // 标签权重2倍
        ).Type("best_fields").Fuzziness("AUTO")
        boolQuery.Must(multiMatch)
    }

    // Filter条件：精确筛选（不影响评分）
    boolQuery.Filter(elastic.NewTermQuery("is_private", false))

    if query.Category != "" {
        boolQuery.Filter(elastic.NewTermQuery("category", query.Category))
    }

    if query.UserID > 0 {
        boolQuery.Filter(elastic.NewTermQuery("user_id", query.UserID))
    }

    // 时间范围筛选
    if query.StartTime != nil {
        rangeQuery := elastic.NewRangeQuery("created_at").Gte(*query.StartTime)
        if query.EndTime != nil {
            rangeQuery.Lte(*query.EndTime)
        }
        boolQuery.Filter(rangeQuery)
    }

    // 执行搜索
    searchResult, err := e.client.Search().
        Index("videos").
        Query(boolQuery).
        Sort("_score", false).
        Sort("created_at", false).
        From(int(query.Offset)).
        Size(int(query.Limit)).
        Do(ctx)

    if err != nil {
        return nil, 0, err
    }

    // 提取ID
    ids := make([]int64, len(searchResult.Hits.Hits))
    for i, hit := range searchResult.Hits.Hits {
        var doc map[string]interface{}
        json.Unmarshal(hit.Source, &doc)
        ids[i] = int64(doc["id"].(float64))
    }

    return ids, searchResult.TotalHits(), nil
}
```

```yaml
        for: 2m
        labels:
          severity: critical
        annotations:
          summary: "服务 {{ $labels.service }} 错误率超过5%"

      - alert: HighLatency
        expr: histogram_quantile(0.99, rate(http_request_duration_seconds_bucket[5m])) > 1
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "服务 {{ $labels.service }} P99延迟超过1秒"

      - alert: ServiceDown
        expr: up == 0
```

```go
    reader    *kafka.Reader
    handler   EventHandler
    processed sync.Map  // 去重
}

func NewVideoConsumer(brokers []string, groupID string, handler EventHandler) *VideoConsumer {
    reader := kafka.NewReader(kafka.ReaderConfig{
        Brokers:        brokers,
        Topic:          "video-events",
        GroupID:        groupID,
        MinBytes:       1e3,   // 1KB
        MaxBytes:       10e6,  // 10MB
        CommitInterval: time.Second,
        StartOffset:    kafka.FirstOffset,
    })
    return &VideoConsumer{reader: reader, handler: handler}
}

func (c *VideoConsumer) Start(ctx context.Context) {
    for {
        msg, err := c.reader.FetchMessage(ctx)
        if err != nil {
            if ctx.Err() != nil {
                return  // 上下文取消，退出
            }
            continue
        }

        // 幂等性检查
        msgID := fmt.Sprintf("%d-%d", msg.Partition, msg.Offset)
        if _, loaded := c.processed.LoadOrStore(msgID, true); loaded {
            c.reader.CommitMessages(ctx, msg)  // 已处理，跳过
            continue
        }

        // 处理消息
        var event VideoEvent
        json.Unmarshal(msg.Value, &event)

        if err := c.handler.Handle(ctx, &event); err != nil {
            // 处理失败，发送到死信队列
            c.sendToDeadLetter(ctx, msg, err)
        }

        // 提交offset
        c.reader.CommitMessages(ctx, msg)
    }
}

func (c *VideoConsumer) sendToDeadLetter(ctx context.Context, msg kafka.Message, err error) {
```

**事件处理器**：
```go
// app/video/infrastructure/mq/handler.go

type EventHandler struct {
    db        repository.VideoDB
    es        repository.VideoElastic
    embedding repository.EmbeddingService
    vector    repository.VectorDB
    recommender repository.Recommender
}

func (h *EventHandler) Handle(ctx context.Context, event *VideoEvent) error {
    switch event.Type {
    case "video.created":
        return h.handleVideoCreated(ctx, event)
    case "video.updated":
        return h.handleVideoUpdated(ctx, event)
    case "video.deleted":
        return h.handleVideoDeleted(ctx, event)
    case "video.liked":
        return h.handleVideoLiked(ctx, event)
    default:
        return fmt.Errorf("unknown event type: %s", event.Type)
    }
}

func (h *EventHandler) handleVideoCreated(ctx context.Context, event *VideoEvent) error {
    video, err := h.db.GetVideoByID(ctx, event.VideoID)
    if err != nil {
        return err
    }

    // 并行处理多个任务
    var wg sync.WaitGroup
    var errs []error
    var mu sync.Mutex

    // 1. 索引到Elasticsearch
    wg.Add(1)
    go func() {
        defer wg.Done()
        if err := h.es.AddItem(ctx, "videos", video, video.Title); err != nil {
            mu.Lock()
            errs = append(errs, fmt.Errorf("ES索引失败: %w", err))
            mu.Unlock()
        }
    }()

    // 2. 生成向量并存储
    wg.Add(1)
    go func() {
        defer wg.Done()
        text := video.Title + " " + video.Description + " " + video.Tags
        embedding, err := h.embedding.GenerateEmbedding(ctx, text)
        if err != nil {
            mu.Lock()
            errs = append(errs, fmt.Errorf("Embedding生成失败: %w", err))
            mu.Unlock()
            return
        }
        if err := h.vector.StoreVector(ctx, video.ID, embedding, nil); err != nil {
            mu.Lock()
            errs = append(errs, fmt.Errorf("向量存储失败: %w", err))
            mu.Unlock()
        }
    }()

    // 3. 注册到推荐系统
    wg.Add(1)
    go func() {
        defer wg.Done()
        if err := h.recommender.InsertItem(ctx, video); err != nil {
            mu.Lock()
            errs = append(errs, fmt.Errorf("推荐注册失败: %w", err))
            mu.Unlock()
        }
    }()

    wg.Wait()

    if len(errs) > 0 {
        return fmt.Errorf("部分任务失败: %v", errs)
    }
    return nil
}
```

```go
// config/config.go

func InitFromEtcd(serviceName string) error {
    // 连接etcd
    cli, err := clientv3.New(clientv3.Config{
        Endpoints:   []string{config.Etcd.Addr},
        DialTimeout: 5 * time.Second,
    })
    if err != nil {
        return err
    }
    defer cli.Close()

    // 获取配置
    resp, err := cli.Get(context.Background(), "/config/"+serviceName)
    if err != nil {
        return err
    }

    if len(resp.Kvs) > 0 {
        yaml.Unmarshal(resp.Kvs[0].Value, &config)
    }

    // 监听配置变化
    go watchConfig(cli, serviceName)

    return nil
}

func watchConfig(cli *clientv3.Client, serviceName string) {
    watchChan := cli.Watch(context.Background(), "/config/"+serviceName)

    for watchResp := range watchChan {
        for _, event := range watchResp.Events {

                var newConfig Config
                yaml.Unmarshal(event.Kv.Value, &newConfig)

                updateHotConfig(&newConfig)

                log.Printf("配置已热更新: %s", serviceName)
            }
        }
    }
}
```
