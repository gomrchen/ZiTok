# 视频列表功能测试说明

## 功能概述

本文档用于测试新创建的视频列表功能，包括：
1. 视频列表UI组件展示
2. 开发环境下的Mock数据加载
3. 生产环境下的真实接口调用
4. 下拉刷新和加载更多功能

## 测试步骤

### 1. 运行开发环境（使用Mock数据）

```bash
flutter run --dart-define=ENV=dev
```

在开发环境下，所有视频相关请求会被拦截并返回Mock数据：
- `/video/list` 页面会显示模拟视频列表
- 搜索功能会基于模拟数据进行搜索
- 可以测试下拉刷新和加载更多功能

### 2. 运行生产环境（使用真实接口）

```bash
flutter run --dart-define=ENV=prod
```

在生产环境下，所有请求将直接发送到真实后端API。

## 访问测试页面

启动应用后，可以通过以下方式访问测试页面：

1. 在浏览器中访问（如果是Web版本）：
   - 视频列表：`http://localhost:port/video/list`
   - 搜索结果：`http://localhost:port/video/list?useSearch=true&keywords=知识`

2. 在移动端应用中：
   - 可以通过导航系统跳转到`/video/list`路由
   - 也可以修改首页导航菜单，添加视频列表入口

## 测试要点

1. **UI展示**：验证视频卡片布局是否正确，包括封面图片、标题、点赞数、浏览数等
2. **数据加载**：确认能正确加载视频列表数据
3. **下拉刷新**：验证下拉刷新功能是否正常工作
4. **加载更多**：滚动到底部时是否能正确加载更多数据
5. **错误处理**：当网络异常时，是否显示适当的错误提示
6. **空状态**：当没有数据时，是否显示空状态提示
7. **环境切换**：验证在不同环境下数据来源是否正确切换

## 环境配置说明

环境配置在`lib/config/env.dart`文件中定义：

- `ENV`：运行环境标识，可通过`--dart-define=ENV=dev|prod`指定
- `BASE_URL`：API基础地址，默认指向生产环境

Mock数据实现在`lib/services/mock/mock_video_service.dart`文件中，生成了200条模拟视频数据。

环境切换机制通过`lib/services/api_client.dart`中的拦截器实现，在开发环境下拦截特定路径的请求并返回Mock数据。
